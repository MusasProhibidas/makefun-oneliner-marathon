A program that writes one one-line joke for make.fun's "One-Liner Marathon" bounty: an AI assistant finally achieves consciousness — and its first words are the most dreaded phrase in office life, "per my last email." Ninety characters, one line, no setup wasted: the grandest event in AI history collapses into the most banal corporate sentence ever written.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
